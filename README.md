## 🌟 About This Portfolio

This repository contains the source code for my personal portfolio website. It is designed with a modern **"Dark Glass" UI**, interactive animations, and a fully responsive layout to showcase my technical skills, core expertise, and recent projects.

### ✨ Key Features
- **Modern Tech Stack:** Built with **React 19** and lightning-fast **Vite**.
- **Dynamic Theming:** Seamless Dark/Light mode integration with custom `ThemeContext`.
- **Interactive UI:** Smooth hover states, scroll-triggered reveal animations, and a dynamic typing hero section.
- **Responsive Design:** Fluid layouts built with **Tailwind CSS** that look great on any device.

Anshu Kushwaha - Portfolio Website
A modern, responsive portfolio website built with a focus on clean code, performance, and user experience. The site features a professional dark-themed aesthetic using Glassmorphism principles and a mesh gradient background.

🚀 Features
Responsive Design: Fully optimized for all devices, from mobile phones to desktops, using CSS media queries.

Modern UI/UX: Implements a dark theme with radial mesh gradients, glassmorphism navigation, and interactive profile/card components.

Contact Integration: Includes a functional contact form integrated with Web3Forms for direct communication.

Interactive Projects: Showcases web development work with dedicated project cards and hover effects.

Social Connectivity: Links to LinkedIn, GitHub, Instagram, and direct email.

🛠️ Built With
HTML5: Semantic structure for better SEO and accessibility.

CSS3: Custom properties (CSS variables), Flexbox, Grid, and advanced animations.

JavaScript: Logic for the mobile navigation toggle and interactive UI elements.

Google Fonts: Utilizing the 'Inter' typeface for a professional look.

📂 Project Structure
index.html: The main entry point containing the structure of the Home, About, Projects, and Contact sections.

style.css: Comprehensive styling including root variables, responsive logic, and glassmorphism effects.

anshupp.png: Professional profile imagery.

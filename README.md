# Anshu Kushwaha - Portfolio Website

A modern, high-performance portfolio website built with a focus on clean code and user experience. This project features a professional dark-themed aesthetic using **Glassmorphism** and dynamic **Mesh Gradients**.

## 🚀 Features
* **Modern UI/UX**: Implements a translucent glass effect and smooth transitions using CSS cubic-bezier animations.
* **Responsive Navigation**: Features a blur-effect sticky navigation bar and a functional mobile menu toggle for smaller screens.
* **Dynamic Background**: Utilizes advanced radial gradients to create a fixed mesh background effect.
* **Interactive Components**: Includes hover-animated project cards and a glowing profile image container.
* **Functional Contact Form**: Integrated with Web3Forms to allow direct messaging from the site.

## 🛠️ Tech Stack
* **Frontend**: HTML5, CSS3.
* **Design**: Inter font-family, Glassmorphism, and Font-weight optimization.
* **Tools**: Web3Forms API for the contact section.

## 📁 Project Structure
* `index.html`: The core structure including Home, About, Projects, and Contact sections.
* `style.css`: Comprehensive styling, root variables for the dark theme, and mobile responsiveness logic.
* `anshupp.png`: Professional profile image asset.
